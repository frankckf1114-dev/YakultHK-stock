首次設定步驟（點開）
  1. 到 supabase.com 免費註冊，建立一個 Project
  2. 左下角 Project Settings → API Keys（或 API）：
    · Project URL
    · Key：優先用 Publishable；若有 Legacy → anon public 也可以
    （不要用 secret / service_role）
  3. SQL Editor 執行以下（只需一次）：
create table if not exists inventory_sync (
  team_code text primary key,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz default now()
);
alter table inventory_sync enable row level security;
drop policy if exists "allow_anon_all" on inventory_sync;
create policy "allow_anon_all" on inventory_sync
  for all to anon, authenticated
  using (true) with check (true);
grant select, insert, update on table inventory_sync to anon, authenticated;

然後你與同事填同一個同步碼，按「儲存同步設定」再「立即同步」。
